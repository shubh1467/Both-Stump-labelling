    How to use
    1. Click the points in the order shown under "Next point".
    2. Mouse wheel zooms, hold Space and drag (or middle button) to pan, 0 fits the image.
    3. Drag a placed point to correct it. Right-click a point to remove it. Click a name in the list, then click the image, to re-place that point.
    4. The dashed boxes are the boxes already in labels/. The saved label uses the box that contains each wicket's points; if none does, a box is calculated from the points.
    5. Save & next writes labels_12pts/<image>.txt (needs all 12 points).
